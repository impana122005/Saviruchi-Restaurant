# Saviruchi Veg Restaurant 🍽️

Saviruchi Veg Restaurant is a responsive restaurant website developed using HTML, CSS, and JavaScript.  
The website provides an interactive online food ordering experience with user authentication, cart management, menu filtering, table reservation, and checkout functionality.

## Features

- User Login & Signup Authentication
- Password Validation with Rules
- Forgot Password Functionality
- Responsive Restaurant UI
- Food Search & Category Filter
- Add to Cart Functionality
- Quantity Increase/Decrease
- Cart Total Calculation
- Checkout & Payment Selection
- Table Reservation System
- Admin Panel for Adding Menu Items
- Local Storage Support
- Fully Responsive Design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
